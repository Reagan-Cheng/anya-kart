# 安妮亞 3D 賽車

給家人在 iPad 上玩的 3D 卡丁車網頁遊戲（Three.js）。

- 遊玩網址：https://reagan-cheng.github.io/anya-kart/
- iPad：用 Safari 打開網址 →「分享」→「加入主畫面」，就能全螢幕玩，也能離線玩。
- 電腦：方向鍵或 WASD 開車、空白鍵煞車、E 鍵用道具、P 暫停。
- 三條賽道（設定在 tracks.js）：花生鄉村（懸崖、斷橋）、城市夜賽（8 字高架橋、隧道、車輛、水窪）、雪山間諜基地（雪球、雷射門、輸送帶、冰面、岔路冰洞、冰湖）。
- 八種道具：火箭衝刺、花生炸彈、煙霧彈、護盾、花生大放送、變大藥水、縮小手電筒、彭德拉車。
